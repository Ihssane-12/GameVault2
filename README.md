# 🎮 GameVault

GameVault is a modern gaming e-commerce web application that allows users to browse, search, and purchase video games بسهولة.

---

## 🚀 Features

* 🔍 Search games by title
* 🎯 Filter by category (Action, RPG, FPS)
* 🛒 Add to cart system
* ➕ Increase / decrease quantity
* ❌ Remove items from cart
* 💾 Cart saved using LocalStorage
* 💳 Checkout simulation
